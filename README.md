# 🎬 Genius IPTV

تطبيق بث احترافي للقنوات والأفلام والمسلسلات

## 📱 المميزات

### الواجهة الرئيسية
- 📺 **القنوات** - مع تصنيفات متعددة (رياضة، أخبار، أطفال، إلخ)
- 🎬 **الأفلام** - مع تصنيفات (جديد، أكشن، درما، إلخ)
- 📺 **المسلسلات** - مع تصنيفات (تركي، مصري، خليجي، إلخ)
- ⚙️ **الإعدادات** - للمستخدمين والإدارة

### نظام الإدارة (Admin Panel)
- ➕ إضافة وتعديل المحتوى
- 🔗 دعم روابط M3U, M3U8, XTREAM
- 👥 إدارة المستخدمين والأكواس
- 🔐 نظام الأكتف كود و Username/Password
- 📅 تحديد مدة الاشتراك
- 📊 إدارة التصنيفات والباقات

## 🎨 التصميم

**الألوان:**
